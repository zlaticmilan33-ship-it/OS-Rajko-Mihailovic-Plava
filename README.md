# OŠ „Rajko Mihailović“ Banjani — sajt (plava verzija)

Statički sajt, bez build koraka.

- `index.html` — početna stranica
- `za-roditelje.html` — Za roditelje
- `izdvojena-odeljenja.html` — Izdvojena odeljenja
- `dokumenti/` — dokumenti za preuzimanje
- `assets/` — fotografije
- `_ds/`, `support.js`, `image-slot.js` — stilovi i skripte (ne brisati)
- `.nojekyll` — obavezan, da GitHub Pages ne bi ignorisao folder `_ds`

## Objavljivanje na GitHub Pages

1. Ceo sadržaj ovog foldera (uključujući `.nojekyll`) postavite u koren repozitorijuma.
2. Settings → Pages → Source: *Deploy from a branch*, grana `main`, folder `/ (root)`.
3. Sajt je dostupan na `https://<korisnik>.github.io/<repozitorijum>/`.
